## Collection contracts

- The two poster feeds bind the current native page/gallery identity and exact JPEG bytes to reviewed SHA256 fingerprints and complete transcriptions. Changed/new program artwork fails for review. Vagabond weekly dates are explicitly bounded through January 12, 2027; static art cannot authorize indefinite projection.
- Hummingbird resolves each of the six exact own-site class IDs to its ordinary public WWW detail page. Native `nextBookableSession` data supplies explicit dates, UTC/local clocks, capacity and cancellation state. A single blank course body uses its exact matched publisher class card; additional session instructions are retained. No widget request or weekly projection occurs.
- Cardboard uses a fixed public establishment GET with the public GenericEvents routing ID advertised in current store SSR. The renderer cannot accept a different host, store, header, method or unbounded date window and never follows redirects with this header. One page of 100 is admitted only when native totals certify a complete list; any additional page fails rather than truncating. Full descriptions come from ordinary public event detail SSR, not list snippets.
- The two longer sources use existing durable checkpoints with two details per invocation and a four-hour lifetime. A completed checkpoint is saved before staging; partial snapshots never publish. Existing credential, ticket, lease and cleanup semantics remain unchanged.
- The shared publisher boundary now supports explicit JPEG/PNG bytes, with matching MIME and magic, the existing 3 MB limit, and unchanged DNS/robots/pacing/deadline protections.
