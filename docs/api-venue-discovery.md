# First-party venue and calendar discovery

This upstream worker is a narrow adapter to EventQuest's existing feed registrar. It is **not** a replacement feed importer or an arbitrary URL crawler.

A FindLocal or Things To Do event already fetched for ordinary search can yield a transient venue candidate. EventQuest creates a 22-hour private queue row; requests are fenced behind database-issued one-use tickets. The external worker calls `community_collector_claim_api_venue_discovery` with its existing collector token; it never accepts raw website URLs from requests. FindLocal supplies a venue website when available. Things To Do supplies the original event source link; that may be a third-party ticketing site, which is held for review rather than misidentified as the official venue.

The collector fetches the candidate first-party page through `fetch_publisher(...respect_robots=True,allowed_hosts=(exact_host,))`. Redirects, disallowed robots rules, private DNS, access denials and publisher pacing preserve existing transport semantics. It requires independently corroborated publisher evidence before returning `verified`; otherwise returns `review`, `retry` or `disabled`. It examines explicit calendar subscription links and at most one linked same-host calendar page. It never guesses that an individual event link is a complete feed. A single supported iCal or WordPress Events Calendar endpoint is passed to `community_register_venue_website` for the existing registrar to confirm. HTML calendar pages without a reusable parser remain candidates for future adapters.

**Data ownership:** The short-lived API queue is deleted, including verified entries, within 22 hours. Only independently checked original publisher URLs pass to the durable `registration_venue_websites` and `feed_registrations` tables; upstream API venue IDs, event payloads and coordinates are not permanently mirrored. Multiple venues linked to one publisher feed deduplicate by registered URL.

**Release sequence:** deploy this Python handler first, then the guarded EventQuest schema migration and dispatcher. Test the six observed Charlotte/New York FindLocal leads and future Bay Area Things To Do searches without forcing additional provider calls; record honest verified/review/blocked counts. A completed venue website is not a published event. Never bypass a publisher's robots denial or invent feed URLs.
